# Akıllı Arama Sunumu

6. sınıf Bilişim Teknolojileri ve Yazılım dersi, 3. tema, BTY.6.3.1 (İnternet ile amacına uygun olarak çalışabilme) için hazırladığım ders materyali.

**Sunumu aç:** https://rizgarozan.github.io/akilli-arama-sunum/

**Etkileşimli sayfa:** https://rizgarozan.github.io/akilli-arama-sunum/sayfa.html

## Sunumu kullanma

- Soru kutusuna dokununca cevap açılır.
- Boşluk tuşu, sağ ok ya da sunum kumandası önce cevapları açar, sonra sonraki slayta geçer. Sol ok geri gider.
- N: öğretmen notları, F: tam ekran.
- Alttaki ↺ Sıfırla düğmesi bütün cevapları kapatır.

İnternet yoksa `index.html` dosyasını indirip tarayıcıda açmak yeterli.
